个人项目视觉设计指导书
适用项目：ChatEZ / TodoList / CodeDrill / Word（普通版）/ Word（墨水屏版）
目标：为后续AI生成UI、插画、图标、启动页、宣传图提供统一设计依据。
# ChatEZ
定位：温暖书房中的AI助手，而非普通聊天软件。
关键词：暖黄色、纸张纹理、书架、台灯、猫、钢笔、手稿、雨夜。
图标建议：打开的书本+聊天气泡+钢笔。
首页：书桌场景、柔和光源、中央输入入口。
对话界面：纸片/信件式消息气泡，弱科技感。
插画方向：阅读、记录、思考、陪伴。
# TodoList
定位：人生控制台。
关键词：深色、橙色强调、控制中心、数据面板、状态监控。
图标建议：圆形仪表盘中的勾选标记。
首页：任务完成率、连续专注天数、项目统计。
视觉风格：赛博控制台，而非便签纸。
插画方向：控制中心、驾驶舱、系统状态。
# CodeDrill
定位：黑客训练营与代码修炼场。
关键词：终端、绿色荧光、CRT显示器、训练场。
图标建议：终端符号 >_ 。
首页：练习统计、成长树、成就系统。
视觉风格：深色背景+绿色信息高亮。
插画方向：程序员、显示器、代码雨、训练系统。
# Word（普通版）
定位：西式古典图书馆中的单词收藏系统。
关键词：书架、羊皮纸、羽毛笔、蜡烛、地球仪。
图标建议：古典书架中的WORD铭牌。
首页：馆藏统计、单词收藏、学习进度。
单词卡：博物馆展品说明牌风格。
插画方向：图书馆、藏书室、馆员、古籍。
# Word（墨水屏版）
定位：静墨书卷。
关键词：留白、枯笔、淡墨、竹、兰、梅、山石。
图标建议：简化山水+印章。
首页：极简布局，低灰阶设计。
视觉风格：静态水墨，不依赖渐变和重渲染。
插画方向：文人书房、器物、花枝、印章。
# 统一AI提示词模板
请严格遵循项目视觉指导书。
保持图标、配色、构图、世界观一致。
优先保证氛围与辨识度，而非炫技。
生成UI时先输出设计分析，再输出布局结构，最后输出代码。
