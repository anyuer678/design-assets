# 个人项目视觉圣经_v1.0.docx

> 自本地 docx 转换（design-assets 视觉圣经）。产品 UI 以本文为准；素材库不得覆盖。

个人项目视觉圣经 v1.0
用途：
作为 ChatEZ、TodoList、CodeDrill、Word（普通版）、Word（墨水屏版）的长期产品设计规范。适用于AI生成UI、插画、图标、启动页、宣传图、Flutter页面开发。
# ChatEZ｜暖色书房 AI
世界观：用户进入一间安静书房，与AI共同思考、记录和成长。
核心情绪：温暖、陪伴、安静、知识感。
主视觉元素：书架、台灯、钢笔、纸张、猫、窗边、雨夜。
主色：米白、浅棕、暖灰；避免高饱和科技蓝。
图标：打开的书本 + 对话气泡。
首页结构：顶部欢迎语 → 最近对话 → 技能入口 → 输入区。
空状态文案示例：'今天想聊些什么？'
插画规范：手绘速写、纸张纹理、暖光漫反射。
禁止：赛博朋克、霓虹灯、大量荧光色。
# TodoList｜人生控制台
世界观：用户不是管理任务，而是在管理人生系统。
核心情绪：掌控感、执行力、成长感。
主视觉：控制中心、仪表盘、数据监控。
主色：深灰 + 橙色强调。
图标：圆形仪表盘中的勾选标记。
首页模块：今日任务、连续专注、项目进度、统计图。
动画：数字滚动、进度增长、系统上线效果。
禁止：便签纸拟物化过重。
# CodeDrill｜代码训练营
世界观：开发者训练场。
核心情绪：挑战、成长、专注。
主视觉：终端、CRT、训练任务。
主色：黑色背景 + 绿色荧光。
图标：>_ 终端符号。
模块：题库、训练场、成长树、成就系统。
成就体系：学徒→开发者→工程师→架构师→传奇。
动画：命令执行、结果反馈、等级升级。
# Word 普通版｜古典图书馆
世界观：收藏单词而非背单词。
核心情绪：探索知识、收藏与积累。
主视觉：木质书架、羊皮纸、古籍、羽毛笔。
主色：深棕、羊皮纸黄、古铜色。
图标：书架中的WORD铭牌。
页面：馆藏大厅、词库书架、单词卡、学习记录。
单词展示：展品卡片风格。
等级体系：见习馆员→馆员→资深馆员→首席馆长。
# Word 墨水屏版｜静墨书卷
世界观：文人书房中的每日修习。
核心情绪：安静、克制、沉浸。
主视觉：留白、淡墨、印章、竹兰梅石。
图标：简化山水与印章。
主色：黑白灰。
禁止：复杂渐变、大面积灰阶。
首页：今日新词、待复习、累计掌握。
插画原则：单个静物即可，不喧宾夺主。
# 统一图标规范
图标保持圆角矩形底板。
避免使用网络常见扁平图标。
图标必须体现项目世界观。
确保缩小到48x48仍可识别。
# AI 生成UI标准流程
先分析设计语言。
输出页面结构树。
输出组件拆分。
输出配色与字体规范。
最后生成Flutter代码。
禁止直接根据图片生成代码。
