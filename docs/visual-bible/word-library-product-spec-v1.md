Word（图书馆版）产品设计规范书 v1.0
# 1. 产品定位
Word不是背单词软件，而是“单词收藏馆”。
核心理念是把学习行为从被动记忆转化为主动收藏。用户不是在刷题，而是在经营一座属于自己的语言图书馆。
目标用户：大学生、英语学习者、考研用户、阅读爱好者。
竞品差异：弱化打卡焦虑，强化沉浸式收藏体验。
# 2. 世界观设计
用户进入一座古典图书馆。
每个单词对应一本藏书。
每个词库对应一个馆区。
学习行为对应整理馆藏。
复习行为对应巡馆。
掌握单词对应正式入藏。
遗忘单词对应待修复馆藏。
等级体系：学徒馆员→见习馆员→馆员→资深馆员→首席馆长。
# 3. 视觉风格
参考欧洲古典图书馆、牛津老图书馆、羊皮纸手稿。
关键词：木质书架、黄铜、羊皮纸、羽毛笔、古籍、蜡烛。
整体避免互联网教育产品的塑料感。
强调历史感、收藏感、知识感。
# 4. 配色系统
主色：深棕色。
背景：羊皮纸暖黄。
强调色：古铜金。
成功状态：墨绿色。
错误状态：酒红色。
禁止高饱和荧光色。
# 5. 图标系统
Logo主体为书架。
中央为Word铭牌。
图标在48px下仍需保持识别度。
风格统一为古典线条与雕刻感。
# 6. 首页设计
顶部展示馆长信息。
中部展示今日待整理藏书。
底部展示各馆区入口。
背景采用轻度纸张纹理。
提供最近学习记录与连续学习统计。
# 7. 学习界面
单词作为馆藏卡片展示。
卡片包含单词、音标、释义、例句、词源。
学习动作对应翻阅馆藏。
收藏动作对应正式入库。
支持沉浸模式。
# 8. 馆藏体系
CET4馆。
CET6馆。
考研馆。
文学馆。
科技馆。
自定义馆。
每个馆有独立进度与统计。
# 9. 成长体系
经验值来源：学习、复习、收藏。
升级后解锁新的馆区装饰。
获得特殊书签、馆藏徽章。
避免数值膨胀。
# 10. 插画规范
插画采用古典绘本风格。
主体包括书架、馆员、古籍、地球仪。
避免二次元角色占据核心。
插画服务于氛围而非功能。
# 11. 动效规范
翻书动画。
馆藏入库动画。
书签滑入动画。
数字增长动画。
保持克制，不使用炫目特效。
# 12. 文案规范
不用“背单词”。
统一使用：收藏、整理、巡馆、入藏。
例如：
今日待整理藏书 20 本。
成功入藏新词 5 个。
# 13. AI绘图提示词
古典图书馆、羊皮纸、木质书架、黄铜细节、暖光、羽毛笔、收藏系统、知识管理、沉浸式阅读。
统一风格输出。

 └ BottomNavigation

 ├ WordCard
 ├ ExampleArea
 ├ CollectionButton
 └ ReviewButton

跨设备同步。
